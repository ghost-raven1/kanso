# Portal

Для модального окна с изоляцией фокуса и Escape используйте [Dialog](dialogs.md).

`Portal` из `@kanso/core` размещает содержимое вне layout, сохраняя Context,
сервисы, реактивные props и владельца cleanup. React DOM не используется.

```tsx
import { Portal, useState } from '@kanso/core';

export function Notice() {
  const [visible, setVisible] = useState(false);

  return (
    <>
      <button onClick={() => setVisible(true)}>Показать уведомление</button>
      {visible && (
        <Portal>
          <aside aria-label="Уведомление">
            <p>Содержимое находится в document.body.</p>
            <button onClick={() => setVisible(false)}>Закрыть</button>
          </aside>
        </Portal>
      )}
    </>
  );
}
```

Без `mount` используется `document.body`. Можно передать `HTMLElement` или
функцию `() => HTMLElement | null`, например:

```tsx
<Portal mount={() => document.getElementById('notifications')}>
  <Notification />
</Portal>
```

`null` означает отсутствие контейнера: дочерние компоненты не создаются.
Функция отслеживает реактивные чтения, но не следит за произвольными изменениями
DOM. Если целевой элемент появляется позднее, храните его в состоянии или
передавайте реактивный prop. `ref.current` сам по себе не является сигналом.

При смене одного непустого контейнера на другой существующие дочерние DOM-узлы
переносятся; состояние не сбрасывается. Фокус при таком перемещении не
гарантируется. При переходе к `null`, удалении `Portal` или уходе с маршрута
дочерние компоненты размонтируются, эффекты очищаются, DOM удаляется. Последующее
монтирование создаёт новое состояние. Solid добавляет служебную обёртку `div`.

На сервере `Portal` ничего не выводит и не вычисляет `mount`/`children`, поэтому
обращение к `document` внутри функции `mount` безопасно. При гидратации содержимое
появляется на клиенте, не заменяя серверный DOM остальных компонентов. Основной
контент и метаданные должны оставаться в SSR-дереве; для head используйте `Seo`.

События Kanso нативные: всплытие следует физическим DOM-предкам, а не JSX-дереву
за пределами портала. Передавайте `onClose`, `onSelect` и другие callbacks явно.
`createPortal(node, target)` не переписывается мигратором автоматически: нужно
проверить момент создания содержимого, контейнер и обработчики.

Portal решает размещение, а не доступность модальных окон. Focus trap, inert,
Escape, блокировка прокрутки и стек модальных окон ещё не входят в его контракт.
В лаборатории `/lifecycle` показана немодальная панель с живым Context, черновиком,
счётчиком и возвратом фокуса после закрытия.
